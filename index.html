Capstone Project

Grading Diabetic Retinopathy from Retinal Fundus Photographs

We built a system that pairs a CNN classifier with an autoencoder, using the autoencoder as a regularizer to fight overfitting on a small, heavily imbalanced medical imaging dataset. The resulting method was later published at IEEE ICCCA 2020.

The screening bottleneck

Diabetic retinopathy is damage to the retina caused by diabetes. Early on it has no symptoms at all — the only way to catch it is to photograph the retina and look. Left alone, it's a leading cause of preventable blindness.

The catch is that "look" currently means a trained doctor reviewing each fundus photo individually. That doesn't scale: doctors can't be everywhere screening is needed, and every image waits in a queue for one to be free. A model that gives a fast, preliminary severity rating — flagging the images that actually need a doctor's eyes — was the whole motivation for this project.

Data & stack

The dataset

31,631 fundus photos from EyePACS, an open retinopathy-screening platform, each graded 0–4 by a clinician. It's real screening data, not a clean benchmark: different camera models, some images inverted, some out of focus or over/underexposed, a handful mislabeled. A separate 53,576-image set was held out for testing.

  • No DR 22,315 (70.5%)
  • Moderate 5,292 (16.7%)
  • Mild 2,443 (7.7%)
  • Severe 873 (2.8%)
  • Proliferative 708 (2.2%)

70% of the training set is healthy retinas — the class imbalance a plain classifier tends to overfit to. More on that in the results below.

Before training: every image resized to 256×256, randomly flipped horizontally and vertically for augmentation, then normalized to zero mean and unit variance.
